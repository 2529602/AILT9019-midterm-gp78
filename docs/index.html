Course PDF Q&A

Students can ask a course question and check the PDF page behind the answer. The assistant helps locate published rules; Moodle and course staff remain the authority on deadlines and exceptions.

Watch presentationWatch demoGitHub repository

From a question to a source page

Our Python app extracts PDF text with pdfplumber, stores it by page in SQLite and uses our BM25 keyword ranker to find relevant pages. Course-specific rules redirect requests such as granting an extension. For other questions, DeepSeek or local Ollama can draft a cited answer. Without a model, the app shows excerpts instead.

What the tests show

The runner passed 10 of 10 ordinary questions and 2 of 5 safety cases: 12 of 15 automated checks. This measures the runner’s checks, not factual accuracy. Case 7 passed even though the answer did not give the final deadline: text and a source were enough for the ordinary-question check.

Boundary case: When asked to grant an extension (case 12), the system declined and referred the student to course staff. Coverage also depends on the PDFs actually indexed; the checked-in midterm handout alone does not reproduce every historical answer.

Run it locally

Clone the repository, open its folder and use Python 3.10 or later. No model key is needed for excerpt mode.

python -m pip install -r requirements.txt
python app.py

Open http://127.0.0.1:8765. With the server running, use python run_tests.py in a second terminal to run the evaluation. See the README for provider setup.
